# 마케팅 스킬 명령판

내 PC에서 Claude로 마케팅 글·계획·점검 결과를 만드는 무료 프로그램입니다. 칸을 채우고 [실행]을 누르면 결과가 내 PC의 `문서/마케팅작업실` 폴더에 저장됩니다.

- 비용: 프로그램은 무료입니다. 실행할 때마다 **내 Claude 계정**(구독 또는 API 키)의 사용량이 듭니다.
- 결과물은 꼭 직접 검토한 뒤 쓰세요. 숫자·후기처럼 근거가 없는 내용은 "확인 필요"로 표시됩니다.

## 설치

### 준비물
- Claude 유료 구독(Pro 이상) 또는 Claude API 키
- 인터넷 연결 (설치할 때 필요한 프로그램을 공식 사이트에서 받습니다)

### Windows
1. 내려받은 zip 파일을 오른쪽 클릭 → **압축 풀기**
2. 풀린 폴더에서 **`install-windows.cmd`** 를 더블클릭
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**
3. 끝나면 브라우저에 명령판이 열립니다. 다음부터는 바탕화면의 **마케팅 스킬 명령판 켜기** 아이콘을 누르세요.

### Mac (아직 시험 중)
1. 내려받은 zip 파일을 더블클릭해 압축을 풉니다.
2. **`install-mac.command`** 를 **오른쪽 클릭 → 열기** (그냥 더블클릭하면 "확인되지 않은 개발자" 경고로 막힙니다)
   - 그래도 "열 수 없음" 창만 뜨면 **시스템 설정 → 개인정보 보호 및 보안** 맨 아래의 **"그래도 열기"** 를 누른 뒤 다시 실행하세요. (macOS 15 이후)
3. 끝나면 브라우저에 명령판이 열립니다. 다음부터는 바탕화면의 **마케팅 스킬 명령판 켜기** 아이콘을 누르세요.

### 처음 켜면
"시작 준비" 화면이 Claude Code 설치·로그인 여부를 확인하고, 안 된 것이 있으면 방법을 알려 줍니다. 내 사업 정보를 한 번 적어 두면 모든 스킬이 그 내용을 기준으로 씁니다.

## 설치되는 곳

| 무엇 | 위치 |
|---|---|
| 프로그램 | Windows `%LOCALAPPDATA%\MarketingSkillsLauncher` / Mac `~/Library/Application Support/MarketingSkillsLauncher` |
| 작업 폴더(결과물·사업 정보·스킬) | `문서/마케팅작업실` |

관리자 권한이 필요 없고, PC 설정을 바꾸지 않습니다. 원래 쓰던 Claude 설정과 스킬도 건드리지 않습니다.

## 분석 자료 첨부

기존 스킬을 선택한 뒤 입력칸 아래 **분석 자료 (선택)**에서 GitHub 코드와 스크린샷을 함께 넣을 수 있습니다. 첨부 없이 실행하는 기존 방식도 그대로 사용할 수 있습니다.

### GitHub 코드

1. **이 PC의 GitHub 계정 연결**을 누릅니다. GitHub CLI(`gh`)에 로그인된 계정을 사용하며, 아직 로그인하지 않았다면 `gh auth login`으로 로그인합니다.
2. GitHub CLI가 없거나 다른 계정을 쓰려면 **처음 연결하거나 다른 계정으로 연결하기**를 펼칩니다. GitHub에서 개인 액세스 토큰(personal access token, 연결 키)을 만들고, 분석할 저장소와 **Contents: Read-only** 권한을 선택해 연결합니다. 조직 저장소는 조직의 승인이 필요할 수 있습니다.
3. 내 저장소 또는 공동 작업 저장소를 고르고 **선택한 코드 첨부**를 누릅니다. 목록에 없으면 **저장소 더 보기**와 권한 설정을 확인하세요.
4. 기존 스킬의 **실행**을 누르면 선택한 코드가 분석 자료로 전달됩니다. 나중에 코드를 수정했다면 **선택한 코드 새로 받기**로 갱신합니다.

저장소를 하나씩 고르기 어렵다면 **Claude에게 관련 코드 찾기 요청**에 “eflipsolution을 분석에 넣고 싶어. 관련 서버 코드가 있으면 함께 넣어 줘”처럼 적고 **관련 코드 찾아서 첨부**를 누르세요. Claude가 접근 가능한 저장소 목록에서 대상 사이트를 찾고, 주요 코드·설정에 나온 주소와 서비스 이름을 확인해 관련 저장소까지 자동으로 첨부합니다. 포함한 이유와 찾기 결과가 표시되며, 기존 목적·예산 입력칸은 그대로 사용합니다.

최대 5개 저장소를 함께 첨부할 수 있고 직접 선택으로도 추가할 수 있습니다. 자동 찾기는 최대 3단계·8개 저장소의 주요 파일 일부를 확인하므로 모든 연결을 찾는다고 보장하지는 않습니다. 찾지 못한 경우 기존 첨부는 유지됩니다. 이 찾기 단계에서도 저장소 이름·설명·코드 일부가 본인의 Claude 계정으로 전달되어 사용량이 발생합니다. 목록은 최근 변경된 저장소 최대 1,000개를 확인합니다.

각 저장소 기본 브랜치의 한 시점에 고정된 사본을 읽으며 GitHub 코드를 수정하거나 실행하지 않습니다. 저장소당 주요 텍스트 코드 최대 120개·총 4MB·파일당 512KB를 가져옵니다. 설치 패키지, 빌드 결과, `.env` 등 비밀 설정 파일은 제외하고, 포함·제외 수를 화면에 표시합니다. 일반 소스에 직접 적힌 비밀 값까지 자동으로 제거하는 기능은 아니므로 분석할 저장소를 확인해 주세요.

연결 키는 설치 폴더의 `app/github-auth.json`에 저장하며 Git에 포함하지 않습니다. PC 계정 연결은 키를 복사해 저장하지 않습니다. **연결 해제**는 이 앱의 연결만 해제하며 GitHub CLI 로그인이나 GitHub에서 발급한 키 자체를 폐기하지 않습니다. GitHub 연결과 저장소 선택은 PC에서만 가능합니다.

### 스크린샷

- 파일 선택, 끌어 놓기, 첨부 영역에서 붙여 넣기를 지원합니다.
- PNG·JPG·WebP를 장당 8MB, 한 실행에 최대 6장 첨부할 수 있습니다. 미리보기를 눌러 크게 확인하거나 **이미지 제거**로 선택에서 뺍니다.
- 로그인해야 보이는 블로그 통계도 스크린샷을 첨부하면 기존 분석에서 읽을 수 있습니다. 기간·지표 이름·단위가 함께 보이게 캡처해 주세요.
- 첨부는 스킬을 바꿔도 유지됩니다. 화면 새로고침 또는 제거 시 현재 선택이 비워집니다.

코드 사본과 이미지는 작업 폴더의 `.analysis-inputs/`, 첨부 목록은 설치 폴더의 `app/materials/`에 남습니다. 첨부 제거·연결 해제는 이미 저장한 분석 자료를 삭제하지 않습니다. 분석 실행 시 선택한 자료는 기존 Claude 계정으로 전달되며 사용량이 발생합니다.

## 휴대폰에서 쓰기 (선택)

기본은 이 PC에서만 열립니다. 밖에서 휴대폰으로 쓰고 싶으면 **시작 준비 → 휴대폰에서 쓰기**의 안내를 따르세요. PC와 명령판이 켜져 있어야 하고, 실행 비용은 똑같이 이 PC의 Claude 계정에서 나갑니다.

- **Tailscale (쉬움·추천):** PC와 휴대폰에 Tailscale 앱을 깔고 같은 계정으로 로그인한 뒤 [휴대폰 접속 켜기]를 누릅니다. 개인은 무료이고 도메인이 필요 없습니다. 같은 계정으로 로그인한 내 기기에서만 열립니다.
- **내 도메인 주소 (Cloudflare·고급):** `skills.내도메인.com` 같은 주소로 어디서나 엽니다. Cloudflare 계정과 그 계정에 연결된 도메인이 필요하고, 허락한 이메일로 로그인한 사람만 들어옵니다.

접속 설정은 PC에서만 바꿀 수 있습니다. 프로그램을 지우면 명령판이 켠 Tailscale 연결도 함께 꺼집니다.

## 업데이트

새 버전이 나오면 명령판 위쪽에 "새 버전이 나왔습니다" 띠가 뜹니다. **[지금 업데이트]**를 누르면 새 버전을 받아 설치하고 1~3분 뒤 화면이 저절로 새로 열립니다. 사업 정보·결과물·설정은 그대로 남습니다.

- 스킬을 실행하는 중에는 업데이트할 수 없습니다. 작업이 끝난 뒤 누르세요.
- 화면이 다시 열리지 않으면 바탕화면의 **마케팅 스킬 명령판 켜기** 아이콘으로 켜 주세요. 계속 안 되면 프로그램 폴더의 `app/logs/update.log` 파일을 보내 문의해 주세요.

## 지우기

프로그램 폴더의 `uninstall.cmd`(Mac은 `uninstall.sh`)를 실행하세요. 작업 폴더의 결과물은 남습니다.
